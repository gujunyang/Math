### 3.2 从 git tag 恢复（整份旧状态）

```bash

# 恢复单个文件到工作区
git checkout pre-course-migration-20261030 -- "<旧路径>"
```

> `AISC5000/midterm-announcement.md`。归档目录按原相对路径存放，方便对照。
