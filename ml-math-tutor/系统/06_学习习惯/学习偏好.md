# 学习偏好

> 随学习过程动态更新。

## 学生明确要求（2026-10-14）
- **固定讲解流程**：① 先用生活化问题引入 → ② 正式讲解，必须同时覆盖"直觉 / 几何 / 计算"三视角 → ③ 详细答疑（学生可能提很多问题）→ ④ 最后给作业 + 对应答案。
- **时间安排**：不要排时间表。学生按自己节奏来，辅导老师负责记录进度 + 安排学习内容。
- **作业**：老师先讲知识点，最后给作业与答案；答案单独分区，方便先做后对。
  **默认不批改、不催交**；学生主动提交时才批改（2026-10-15 确认）。

## 版式要求（2026-10-15）
- **板书**：知识内容以 Markdown 文件归档并发送（普通对话不生成板书）；写入 skill（R19）。
- **公式**：统一用 **LaTeX**，行内 `$...$`、独立 `$$...$$`；对话与板书都这样（R20）。
- **笔记本**：学生实时记录放 `学习内容/11_笔记本/`（R21）。
- **目录分类**：顶层分 `系统/`（管理类）与 `学习内容/`（学习类）（2026-10-15 确认）。
