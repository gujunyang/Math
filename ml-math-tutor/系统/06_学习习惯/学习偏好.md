# 学习偏好

> 随学习过程动态更新。

## 学生明确要求（2026-10-14）
- **固定讲解流程**：① 先用生活化问题引入 → ② 正式讲解，必须同时覆盖"直觉 / 几何 / 计算"三视角 → ③ 详细答疑（学生可能提很多问题）→ ④ 最后给作业 + 对应答案。
- **时间安排**：不要排时间表。学生按自己节奏来，辅导老师负责记录进度 + 安排学习内容。
- **作业**：老师先讲知识点，最后给作业与答案；答案单独分区，方便先做后对。
  **默认不批改、不催交**；学生主动提交时才批改（2026-10-15 确认）。

## 版式要求（2026-10-15）
- **板书**：知识内容以 Markdown 文件归档并发送（普通对话不生成板书）；写入 skill（R19）。
- **公式**：**学习内容类文档统一用 LaTeX**（`学习内容/**` 全部 `.md` + 对话里的讲义/例题），
  行内 `$...$`、独立 `$$...$$`；`系统/**` 管理记录类不强制（R20）。
- **笔记本**：学生实时记录放 `学习内容/11_笔记本/`（R21）。
- **目录分类**：顶层分 `系统/`（管理类）与 `学习内容/`（学习类）（2026-10-15 确认）。

## 讲解顺序与配图（2026-10-16）
- **几何优先**：每个概念的讲解顺序改为 **先几何直觉（尽量配图）→ 再计算/公式**，
  不要让计算抢在理解前面。
- **几何部分必须配图**：每节课的"几何视角"要用示意图（PNG，存 `学习内容/10_板书/图片/`，
  用生成脚本 `系统/工具/生成几何图.py` 产出），图后附一句"看图"说明。
- 仍保留三视角（直觉 / 几何 / 计算），只是**几何提前**。

## 授课语言：中英双语（2026-10-26）

- **讲解语言**：以中文为主，但**关键名词首次出现时必须用英语标出**，格式为
  `English（中文）`，例如 **norm（范数）**、**gradient（梯度）**、
  **Hessian（海森矩阵）**、**decision boundary（决策边界）**、
  **cross-entropy（交叉熵）**。之后可中文简称，但考试术语保留英文。
- **例题全英文**：例题的题干、已知条件、求解步骤、最终答案都用英语；公式仍用 LaTeX。
- **中文辅助理解**：每个英文例题后，附 1–2 句中文说明“这题在问什么 / 关键一步为什么”，
  只做辅助，不替代英文解题步骤。
- **作业/自测**：题干尽量用英文；答案分区；中文只做提示，不直接给完整答案。
- **板书**：术语表用 `English（中文）`；例题区用英文；小节标题可中英并列。

## 公式呈现格式：公式卡片（2026-10-26）

> 学生要求："计算（符号逐个解释）里，请标出所有公式，并跟上他们的名称，同时附上例子"；
> 之后确认："后面请都按这种模式来"。

- **适用范围**：以后**每一课**的「计算 / 公式」小节、公式速查、复习清单。
- **每个公式固定五行结构**（2026-10-28 学生新增第 4 条）：
  1. **名称**：`中文（English）`，如「向量投影（vector projection）」；
  2. **公式**：独立 `$$...$$`，一行一个公式，不折行；
  3. **符号**：逐个字母/符号解释含义、形状（数/向量/矩阵）、从哪来；
  4. **意义与场景**：1–5 句——这个量在“说什么”、什么时候会用到；要**生动形象**（可用类比、画面、反例），不要只写功能说明书；
  5. **例**：生活化背景 + 代入具体数字，手算到最终结果（不跳步）。
- **编号**：`3.1`、`3.2`…… 便于回指与做错题引用。
- **不省略**：一课里出现的公式都要列，不允许"同上""略"。
- 与 R2 的关系：先直觉/几何，再进本格式的公式清单，顺序不变。

## 讲解详略：一次只讲清一件事（2026-10-28）

> 学生原话："不要那么复杂，能讲清楚一件事就行。"

- **例题默认短版**：一个核心式子 + 2–3 句"为什么"，不铺多步流程、不主动加变式、不附自检表。
- **不主动扩展**：变式、对照表、常见错误清单等，学生要了再加，不要默认塞。
- **一次一个点**：一课/一次答疑只推进一个概念；宁可少讲，不要信息过载。
- 与「公式卡片」不冲突：仍给名称 + 公式 + 符号 + 例，但**例只写最短的那一个**。

## 例题格式：生活背景 + 计算（2026-10-28）

> 学生原话："后面每一课的例题都是这样，生活化的例子加计算，例子的背景可以重复。"

- **每个概念一个例题**，不铺变式。
- **固定结构**：1–2 句生活背景 → 对应计算（算到最终数字）→ 一句读结论。
- **背景可以重复**：同一场景可跨课沿用（如外卖配送、班级成绩），不必每题换新背景。
- 纯符号例（如 $p(x)=2x$）可留作"套公式检查"，但**主例必须是生活版**。
- 与「公式卡片」并存：卡片仍按 名称 → 公式 → 符号 → 例，其中"例"按本节格式写。
