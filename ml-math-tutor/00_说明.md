# ml-math-tutor —— 机器学习数理基础辅导

一个结构化的学习仓库，用于按依赖顺序掌握机器学习（Machine Learning, ML）所需的
线性代数与微积分。

## 怎么用

**开始一次学习**：本项目已**自动加载**该技能（入口
`.opencode/skills/ml-math-tutor/SKILL.md`，见下）。你直接说要学什么即可，例如
`"开始学习"` / `"继续学线性代数"` / `"讲一下内积"`。
我会自动执行启动协议（读 skill → 整理上次会话 → 分配新会话ID → 输出衔接摘要 → 等确认）。

> 自动加载仅在 **Math 项目**内生效（项目级），打开其它项目不会加载。
> 首次启用或改了技能文件后，需**重启 opencode** 才生效。

**记笔记**：随时写在 `学习内容/11_笔记本/` 里；也可以说 `记笔记：……` 让我代记。
详见 `学习内容/11_笔记本/00_索引.md`。

**改系统后自检**（R22）：在仓库根运行 `python3 ml-math-tutor/系统/工具/自检.py`，
全绿才算改好；出错用 git 回滚（重大改动前先 commit）。

**学习过程中**：每次只推进一个小概念，按你的偏好流程讲：
生活化引入 → 直觉/几何/计算三视角（**几何优先，几何部分配图**，见 R2/R23）→ 详细答疑 → 作业+答案（分区）。
每轮对话我都会即时记录（防丢进度）。

**语言**：中英双语；关键名词用英语标出（如 **norm（范数）**、**gradient（梯度）**），
例题题干与解题步骤用英语，例题后附 1–2 句中文辅助理解。

**结束一次学习**：说 `"今天到这"` / `"结束"` / `"下次再学"` 等，
我会收尾并写会话摘要与会话日志。忘说也没关系，跨天或下次启动会自动补。

## 命名规范

- 文件夹名与 `.md` 文档名使用**中文**。
- `系统/09_辅导老师` 内的技能文件保留英文名（`SKILL.md` 等）。
- 数据/配置文件保留英文名：`progress.json`、`habits.jsonl`、`skill_metadata.yaml`。
- 重要数学名词与术语，第一次出现时同时标注英文。
- **本项目所有数学公式统一用 LaTeX**：行内 `$...$`，独立 `$$...$$`；适用于仓库内
  所有 `.md` 文件（对话与板书、笔记、习题、诊断、进度、摘要、模板等），不只是对话与板书。

## 优先级

- **必学**：必须理解并能独立计算/推导，ML 高频使用。
- **掌握**：能理解含义、会基本计算、知道典型用途。
- **了解**：知道名字、直觉、用途和大概位置即可。
