# 笔记本 · 索引与用法

> 这是**你的**笔记本，用于**实时记录**。与 `学习内容/10_板书/`（我讲的讲义）分开：
> 板书 = 老师给的；笔记本 = 你自己记的。

## 怎么用
1. **你直接编辑**：打开下面任意 `.md` 文件，随手写。
2. **让我代记**：对我说一句 `记笔记：……` 或 `记到待问清单：……`，
   我会按 `日期 时间` 追加到对应文件（R21）。
3. 我不会改动你写的内容；如需补充说明，只会另起一行标注 `> 老师补注：`。

## 文件

| 文件 | 用途 |
|---|---|
| `随手记.md` | 实时随手记，按时间追加：灵感、疑问、小结、错因 |
| `待问清单.md` | 攒下的问题，上课集中问，答完打勾 |
| `必会_L07_二阶判别与完整手算.md` | 应学生要求整理的**必会速查卡**（7.7 判别法 + 最小二乘 Hessian 完整手算）；考前扫一遍 |
| `必会_L11_多维密度五步流程.md` | **必会速查卡**：多维 Gaussian 密度的五步计算流程 + 中文完整手算 + 易错 5 条 |
| `必会_公式文档.md` | **持续增补的公式库**：按课次编号（从 12.1 起）；目前收录 L12 的 $\hat\mu_{\mathrm{ML}}$、$\hat\sigma^2_{\mathrm{ML}}$、$s^2$，后面继续加 |
| `练习题.md` | **题目翻译 + 解答 + 分析**：HW3 Q1/Q4（线性判别、不平衡分类指标）与 HW1 第 4 题（正则化最小二乘、Hessian、梯度下降），每题按“公式索引 → 解答 → 分析”展开 |

## 记录建议（可选）
- 学完一个概念，写一句"我的一句话理解"（能写出来才算真懂）。
- 卡住的地方写清"卡在哪一步"，比写"不会"更有用。
- 每天结束记一条"今天最清楚的一点 / 最糊涂的一点"。
