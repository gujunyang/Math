# 概念优先级表

> 必学 = 必须会算会推；掌握 = 懂含义会算；了解 = 知道名字与用途。

## 必学

| 概念 | 一句话 | ML 用途 |
|---|---|---|
| 向量 | 一列数，表示一个点/方向/特征 | 样本特征、参数 |
| 内积 | 对应相乘再相加 | 相似度、投影、线性模型 |
| 范数 L2 | 向量长度 | 距离、正则化 |
| 矩阵乘法 | 行乘列的批量内积 | 线性变换、前向传播 |
| 转置 | 行列互换 | 正规方程、SVD |
| 线性无关/张成 | 能否被其他向量拼出 | 特征共线、可解性 |
| 正交与投影 | 垂直、投影到子空间 | 最小二乘 |
| 线性模型 ŷ=Xw | 预测 = 特征×权重 | 回归 |
| 残差 | 真实−预测 | 损失 |
| 正交性条件 Xᵀr=0 | 残差与特征列垂直 | 最小二乘解 |
| 最小二乘估计 | 让残差平方和最小 | 线性回归 |
| 正规方程 | XᵀXw=Xᵀy | 直接求最优解 |
| 特征值/特征向量 | 变换下方向不变、只被拉伸 | PCA、稳定性 |
| SVD | 任意矩阵=旋转×拉伸×旋转 | 降维、伪逆、低秩 |
| 梯度（标量对向量）| 增长最快的方向 | 梯度下降 |
| 链式法则 | 复合函数求导 | 反向传播 |
| 反向传播/自动微分 | 高效算所有梯度 | 神经网络训练 |
| 二阶导 | 曲率 | 凸性、牛顿法 |
| 海森矩阵 | 二阶偏导方阵 | 二阶优化、凸性判定 |
| 泰勒展开 | 用多项式局部逼近函数 | 牛顿法、误差分析 |

## 掌握

| 概念 | 一句话 | ML 用途 |
|---|---|---|
| 范数 L1/L∞ | 绝对值之和 / 最大值 | Lasso、鲁棒性 |
| 距离与余弦相似度 | 远近 / 夹角 | 推荐系统、检索 |
| 矩阵逆 | 解线性方程 | 闭式解 |
| 投影矩阵 | 投到列空间 | 最小二乘闭式 |
| 特征分解 A=QDQᵀ | 对称矩阵对角化 | PCA、谱聚类 |
| 奇异值 | √(XᵀX 特征值) | 条件数、SVD |
| 伪逆 | 非方阵的"逆" | 最小范数解 |
| 图拉普拉斯谱 | 图的连通信息 | 谱聚类、GNN |
| 雅可比矩阵 | 向量对向量求导 | 多输出系统 |
| 梯度下降 | 沿负梯度走 | 训练 |
| 凸性 | 只有一个谷底 | 保证全局最优 |
| 岭回归/L2 正则 | 加 ‖w‖² 惩罚 | 防过拟合 |

## 了解

| 概念 | 一句话 | ML 用途 |
|---|---|---|
| 低秩近似 | 用少数主方向近似矩阵 | 压缩、去噪 |
| 代数连通度 | Laplacian 第二小特征值 | 图连通性/聚类 |
| 牛顿法 | 用海森加速优化 | 二阶优化 |
| 计算图 | 把运算画成图 | 自动微分 |
| 分子/分母布局 | 矩阵微分的排版约定 | 查表求导 |
