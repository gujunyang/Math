# MathTutor OS —— 数学辅导系统

一个结构化的数学辅导系统，用于按依赖顺序掌握机器学习（Machine Learning, ML）所需的
线性代数、微积分、概率与优化；也可以扩展到其他数学课程。

## 怎么用

**开始一次学习**：本项目已**自动加载**该技能（入口
`.opencode/skills/math-tutor-os/SKILL.md`，见下）。你直接说要学什么即可，例如
`"开始学习"` / `"继续学线性代数"` / `"讲一下内积"`。
我会自动执行启动协议（读 skill → 整理上次会话 → 分配新会话ID → 输出衔接摘要 → 等确认）。

> 自动加载仅在 **MathTutor OS 项目**内生效（项目级），打开其它项目不会加载。
> 首次启用或改了技能文件后，需**重启 opencode** 才生效。

**记笔记**：随时写在 `学习内容/05_笔记本/` 里；也可以说 `记笔记：……` 让我代记。
详见 `学习内容/05_笔记本/00_索引.md`。

**改系统后自检**（R22）：在仓库根运行 `python3 math-tutor-os/系统/05_工具/自检.py`，
全绿才算改好；出错用 git 回滚（重大改动前先 commit）。

**学习过程中**：每次只推进一个小概念，按你的偏好流程讲：
生活化引入 → 直觉/几何/计算三视角（**几何优先，几何部分配图**，见 R2/R23）→ 详细答疑 → 作业+答案（分区）。
每轮对话我都会即时记录（防丢进度）。

**语言**：中文为主；关键名词用 `English（中文）` 标出（如 **norm（范数）**、**gradient（梯度）**）。
完整手算用中文（第 1 步 / 第 2 步……），公式用 LaTeX；需要模拟英文考卷时临时切英文。

**结束一次学习**：说 `"今天到这"` / `"结束"` / `"下次再学"` 等，
我会收尾并写会话摘要与会话日志。忘说也没关系，跨天或下次启动会自动补。

## 命名规范

- 文件夹名与 `.md` 文档名使用**中文**。
- `系统/04_辅导老师` 内的技能文件保留英文名（`SKILL.md` 等）。
- 数据/配置文件保留英文名：`progress.json`、`habits.jsonl`、`skill_metadata.yaml`。
- 重要数学名词与术语，第一次出现时同时标注英文。
- **学习内容类文档统一用 LaTeX**（`学习内容/**` 全部 `.md`，加上对话里的讲义/例题）：
  行内 `$...$`，独立 `$$...$$`；`系统/**` 的管理记录类文档不强制，已写 LaTeX 的保留。

## 目录

顶层分两大类：**`系统/`**（管理与系统类）和 **`学习内容/`**（学习内容类）。
系统/ 与 学习内容/ **各自独立编号，均从 01 开始**。

### 系统/ —— 管理与系统类

| 目录 | 用途 |
|---|---|
| `系统/01_学习进度/` | 进度、对话记录、错题本、复习队列、会话摘要、系统变更记录 |
| `系统/02_学习习惯/` | 学习习惯记录与偏好 |
| `系统/03_模板/` | 习题模板 |
| `系统/04_辅导老师/` | 辅导老师 skill 定义（英文文件名） |
| `系统/05_工具/` | 维护工具（`自检.py`：一致性检查；`生成几何图.py`：生成板书几何图） |

### 学习内容/ —— 学习内容类

| 目录 | 用途 |
|---|---|
| `学习内容/01_学习计划/` | 学习路线、概念优先级、概念登记表 |
| `学习内容/02_知识图谱/` | 知识图谱（Mermaid） |
| `学习内容/03_习题/` | 习题，按 必学/掌握/了解 分级 |
| `学习内容/04_板书/` | 每节课的完整讲义（Markdown，持续归档整理） |
| `学习内容/05_笔记本/` | 学生自己的实时笔记与待问清单 |

## 优先级

- **必学**：必须理解并能独立计算/推导，ML 高频使用。
- **掌握**：能理解含义、会基本计算、知道典型用途。
- **了解**：知道名字、直觉、用途和大概位置即可。
