# 学习偏好

> 随学习过程动态更新。

## 学生明确要求（2026-10-14）
- **固定讲解流程**：① 先用生活化问题引入 → ② 正式讲解，必须同时覆盖"直觉 / 几何 / 计算"三视角 → ③ 详细答疑（学生可能提很多问题）→ ④ 最后给作业 + 对应答案。
- **时间安排**：不要排时间表。学生按自己节奏来，辅导老师负责记录进度 + 安排学习内容。
- **作业**：老师先讲知识点，最后给作业与答案；答案单独分区，方便先做后对。
  **默认不批改、不催交**；学生主动提交时才批改（2026-10-15 确认）。

## 版式要求（2026-10-15）
- **板书**：知识内容以 Markdown 文件归档并发送（普通对话不生成板书）；写入 skill（R19）。
- **公式**：**学习内容类文档统一用 LaTeX**（`学习内容/**` 全部 `.md` + 对话里的讲义/例题），
  行内 `$...$`、独立 `$$...$$`；`系统/**` 管理记录类不强制（R20）。
- **笔记本**：学生实时记录放 `学习内容/05_笔记本/`（R21）。
- **目录分类**：顶层分 `系统/`（管理类）与 `学习内容/`（学习类）（2026-10-15 确认）。

## 讲解顺序与配图（2026-10-16）
- **几何优先**：每个概念的讲解顺序改为 **先几何直觉（尽量配图）→ 再计算/公式**，
  不要让计算抢在理解前面。
- **几何部分必须配图**：每节课的"几何视角"要用示意图（PNG，存 `学习内容/04_板书/图片/`，
  用生成脚本 `系统/05_工具/生成几何图.py` 产出），图后附一句"看图"说明。
- 仍保留三视角（直觉 / 几何 / 计算），只是**几何提前**。

## 授课语言：中英双语（2026-10-26）

- **讲解语言**：以中文为主，但**关键名词首次出现时必须用英语标出**，格式为
  `English（中文）`，例如 **norm（范数）**、**gradient（梯度）**、
  **Hessian（海森矩阵）**、**decision boundary（决策边界）**、
  **cross-entropy（交叉熵）**。之后可中文简称，但考试术语保留英文。
- **例题全英文**：例题的题干、已知条件、求解步骤、最终答案都用英语；公式仍用 LaTeX。
- **中文辅助理解**：每个英文例题后，附 1–2 句中文说明“这题在问什么 / 关键一步为什么”，
  只做辅助，不替代英文解题步骤。
- **作业/自测**：题干尽量用英文；答案分区；中文只做提示，不直接给完整答案。
- **板书**：术语表用 `English（中文）`；例题区用英文；小节标题可中英并列。

## 公式呈现格式：公式卡片（2026-10-26）

> 学生要求："计算（符号逐个解释）里，请标出所有公式，并跟上他们的名称，同时附上例子"；
> 之后确认："后面请都按这种模式来"。

- **适用范围**：以后**每一课**的「计算 / 公式」小节、公式速查、复习清单。
- **每个公式固定五行结构**（2026-10-28 学生新增第 4 条）：
  1. **名称**：`中文（English）`，如「向量投影（vector projection）」；
  2. **公式**：独立 `$$...$$`，一行一个公式，不折行；
  3. **符号**：逐个字母/符号解释含义、形状（数/向量/矩阵）、从哪来；
  4. **意义与场景**：1–5 句——这个量在“说什么”、什么时候会用到；要**生动形象**（可用类比、画面、反例），不要只写功能说明书；
  5. **例（三段式）**：① **背景与题干**（1–3 句中文，给具体数字/条件/要求什么）；② **解**（Step 1 / Step 2 / …，代入 → 中间结果 → 最终数字与单位，不跳步）；③ **解读**（1–2 句，说明这个数意味着什么 + 一个常见误读或考场提醒）。
- **编号**：`3.1`、`3.2`…… 便于回指与做错题引用。
- **不省略**：一课里出现的公式都要列，不允许"同上""略"。
- 与 R2 的关系：先直觉/几何，再进本格式的公式清单，顺序不变。
- **语言分工（2026-10-28）**：公式卡内的「例」用中文（背景/解/解读）；§4 完整手算仍用英文步骤 + 1–2 句中文辅助。

## 讲解详略：一次只讲清一件事（2026-10-28）

> 学生原话："不要那么复杂，能讲清楚一件事就行。"

- **例题默认短版**：一个核心式子 + 2–3 句"为什么"，不铺多步流程、不主动加变式、不附自检表（**公式卡的「例」除外**：按三段式写全）。
- **不主动扩展**：变式、对照表、常见错误清单等，学生要了再加，不要默认塞。
- **一次一个点**：一课/一次答疑只推进一个概念；宁可少讲，不要信息过载。
- 与「公式卡片」不冲突：仍给名称 + 公式 + 符号 + 例；**每张卡一个例，不铺变式**，按三段式写全（背景/解/解读）。

## 例题格式：生活背景 + 计算（2026-10-28）
> 学生原话："后面每一课的例题都是这样，生活化的例子加计算，例子的背景可以重复。"

- **每个概念一个例题**，不铺变式。
- **固定结构**：1–2 句生活背景 → **解**（Step 1 / Step 2 / …，算到最终数字）→ 1 句读结论；与公式卡的三段式一致。
- **背景可以重复**：同一场景可跨课沿用（如外卖配送、班级成绩），不必每题换新背景。
- 纯符号例（如 $p(x)=2x$）可留作"套公式检查"，但**主例必须是生活版**。
- 与「公式卡片」并存：卡片仍按 名称 → 公式 → 符号 → 例，其中"例"按本节格式写。

## 例题语言：完整手算用中文（2026-10-28）

> 学生原话："完整手算要中文的。"

- **完整手算（§4）与同型练习**：题干、步骤、答案**一律中文**；步骤写成「第 1 步 / 第 2 步 …」，不跳步。
- **公式与术语不变**：仍用 LaTeX，关键名词仍标 `English（中文）`，不因中文而丢英文术语（考卷是英文）。
- **与旧偏好的关系**：2026-10-26 的「例题全英文 + 中文辅助」对**完整手算**不再适用；公式卡的「例」本来就用中文（2026-10-28），两者现在一致。
- **练习题干**：默认中文；需要模拟英文考卷时临时切英文。
- **回溯**：第 09–13、14–23 课板书的 §4 若仍是英文步骤，遇到该课复习/讲解时顺手改中文，不做一次性大返工。

## 公式卡「例」模板（2026-10-29，源自 L16 16.1–16.4）

> 学生原话："16 课这些计算（公式卡片）的例都很好，请将这种提炼为模板。"

**适用**：所有公式卡的「例」，尤其是带数值计算、需要说清“每个量是什么”的卡。
**篇幅**：一张卡只写**一个例**，$3\sim6$ 个 Step；不铺变式、不附额外自检表。

**骨架（照填）**

1. **背景与题干**（1–3 句中文）
   - 一句生活场景 + 已知数字（带单位）+ 要求算什么。
2. **解**
   - **Step 0｜拆公式**：按“角色”拆开——谁管高度、谁管衰减；谁是残差项、谁是常数项。必要时用 $\underbrace{\cdots}_{\text{角色}}$ 标出每块的作用，并把符号“挂号”（含义 + 单位）。
   - **Step 1 … Step n｜逐步代入**：一步只做一个动作；先算中间量（$z$、平方和 $S$、行列式、系数），每个中间量都写出数值与单位，不合并不心算。
   - **检查（至少一种）**：① 换路径互验（拆块相乘 vs 直接代公式）；② 换点/换参数对照（列表：中心 / $1\sigma$ / $2\sigma$；MLE vs 无偏）。
3. **解读**（1–2 句）
   - 这个数在说什么（量级 + 单位）；
   - 一个常见误读或考场提醒（密度≠概率；$\sigma^2_{ML}$ 除 $N$ 不除 $N-1$；$\ell$ 不是概率）。

**五个硬要求**

- 符号先挂号、后使用：每个字母第一次出现就说清“是什么、什么单位”。
- 中间结果必须可见（如 $0.9974$、$0.6065$、$2.5$、$1.58$ 都要出现在文中）。
- 单位跟着数字走（$\text{mm}^{-1}$、$\mathrm{g}^2$、$\mathrm{g}$）。
- 至少一次自检，优先用**极端情形**（$N=1$、$t=\mu$、$z=0$、残差全 0）。
- 数字不得与同一课 §4 完整手算 / §5 复现重复（防止背答案）。

**反例（不要这样写）**：`Step 1 平方和 2；Step 2 代入得 -3.03。`——中间量缺失、没有检查、没有解读。

**与旧规则的关系**：本模板细化 2026-10-28 的三段式（背景 → 解 → 解读），不改变九段结构与“一卡一例”的约定。
